方式一：扫码登录（推荐）

  1. 点击"生成二维码"按钮
  2. 打开手机上的 115 App 或 115生活（微信小程序）
  3. 使用"扫一扫"扫描下方二维码
  4. 在手机上确认登录
  5. 系统会自动获取 Cookie 并更新到 alist
点击下方按钮生成二维码
等待扫码...

方式二：手动输入 Cookie

在浏览器登录 115.com， 按 F12 打开开发者工具 → Network → 刷新页面 → 找到 Cookie，复制包含 UID/CID/SEID/KID 的完整字符串。
