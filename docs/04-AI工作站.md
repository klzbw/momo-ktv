# 墨墨爱K歌 - AI工作站配置指南

> 本指南讲解如何配置AI工作站，为没有歌词的歌曲自动生成精准的逐字歌词。包含一键安装、图形化界面、常见问题解决。

---

## 一、AI工作站是什么？

AI工作站是一台有Nvidia独立显卡的Windows电脑，运行AI模型为歌曲自动生成精准歌词。

### 它能做什么？

- 🎤 **人声分离**：把一首歌分离成人声和伴奏（Demucs）
- 📝 **语音识别**：识别人声里的歌词文字和每个字的时间点（WhisperX）
- ✨ **歌词匹配**：把识别结果和官方歌词对齐，修正错别字，生成逐字时间轴
- 🎵 **最终效果**：唱到哪个字哪个字变色，就像KTV里一样

### 为什么需要单独的电脑？

- AI模型需要独立显卡（Nvidia GPU）才能跑得快
- 飞牛NAS通常没有显卡，跑AI会非常慢甚至跑不动
- 把AI任务放在单独的电脑上，NAS只做存储和服务端，各司其职

## 二、硬件要求

### 最低配置（能跑，速度慢）

| 部件 | 要求 |
|------|------|
| 显卡 | Nvidia GTX 1060 6GB 以上 |
| 内存 | 16GB |
| 硬盘 | 50GB可用空间（模型+缓存） |
| 系统 | Windows 10/11 64位 |
| 网络 | 能访问互联网（下载模型） |

### 推荐配置（速度快，体验好）

| 部件 | 要求 |
|------|------|
| 显卡 | Nvidia RTX 3060 12GB 以上 |
| 内存 | 32GB |
| 硬盘 | 100GB SSD（模型+缓存+临时文件） |
| 系统 | Windows 11 64位 |
| 网络 | 千兆有线网络 |

### 各显卡处理速度参考

| 显卡 | 3分钟歌曲处理时间 | 显存占用 |
|------|-------------------|---------|
| GTX 1060 6GB | 约10-15分钟 | ~5GB |
| RTX 2060 6GB | 约6-8分钟 | ~5GB |
| RTX 3060 12GB | 约3-4分钟 | ~6GB |
| RTX 3070 8GB | 约2-3分钟 | ~6GB |
| RTX 4070 Ti SUPER 16GB | 约1.5-2分钟 | ~7GB |

> 💡 处理时间 = 人声分离 + 语音识别 + 歌词匹配，三部分加起来。

## 三、一键安装（图形化界面）

### 第1步：下载AI工作站

从GitHub下载最新版AI工作站工具包：
```
https://github.com/klzbw/momo-ktv/releases
```
下载 `AI-WorkStation-Setup.exe`（一键安装包）。

### 第2步：运行安装程序

1. 双击 `AI-WorkStation-Setup.exe`
2. 选择安装目录（建议 `D:\AI-WorkStation`，不要装C盘）
3. 点击「安装」，等待完成
4. 安装过程会自动：
   - 安装Python 3.10（虚拟环境，不影响系统Python）
   - 安装PyTorch + CUDA（GPU加速）
   - 安装Demucs（人声分离模型）
   - 安装WhisperX（语音识别模型）
   - 下载AI模型文件（约4GB，首次安装需要下载）

### 第3步：启动图形化界面

安装完成后，桌面会有「墨墨AI工作站」图标，双击启动。

### 第4步：配置服务器连接

1. 在「服务器地址」输入你的NAS地址（如 `192.168.3.16:8083`）
2. 输入管理员密码
3. 点击「测试连接」，显示「连接成功」就可以了
4. 点击「保存设置」

### 第5步：启动Worker

点击「▶️ 启动Worker」，AI工作站就会自动从服务器领取任务并处理。

- Worker会持续运行，有新任务就自动处理
- 处理完的歌词会自动上传到服务器
- 下次播放那首歌时就有精准歌词了

## 四、手动安装（如果一键安装失败）

如果一键安装包出问题，可以手动安装，步骤如下：

### 第1步：安装Python 3.10

1. 下载 [Python 3.10.11](https://www.python.org/downloads/release/python-31011/)
2. 安装时勾选「Add Python to PATH」
3. 安装完成后，打开CMD验证：
```bash
python --version
# 应该显示 Python 3.10.11
```

### 第2步：安装Git

1. 下载 [Git for Windows](https://git-scm.com/download/win)
2. 一路下一步安装即可

### 第3步：下载AI工作站代码

```bash
D:
cd D:\
git clone https://github.com/klzbw/momo-ktv.git
cd momo-ktv\ai-worker
```

### 第4步：创建虚拟环境并安装依赖

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
.venv\Scripts\activate

# 升级pip
python -m pip install --upgrade pip

# 安装PyTorch（GPU版，CUDA 12.4）
pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124

# 安装其他依赖
pip install -r requirements.txt
```

### 第5步：验证安装

```bash
# 验证GPU是否可用
python -c "import torch; print('CUDA可用:', torch.cuda.is_available()); print('显卡:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else '无')"
```

显示 `CUDA可用: True` 和显卡型号就成功了！

### 第6步：配置并启动

编辑 `config.json`（如果没有就复制 `config.example.json`）：

```json
{
  "server_url": "http://192.168.3.16:8083",
  "admin_password": "admin888",
  "device": "cuda",
  "demucs_model": "htdemucs",
  "whisper_model": "large-v2",
  "batch_size": 1
}
```

启动Worker：

```bash
.venv\Scripts\activate
python worker.py
```

## 五、防闪退常见问题解决

AI工作站闪退通常是以下原因，按顺序排查：

### 问题1：CUDA不兼容（最常见）

**症状**：启动后立刻闪退，日志显示 `CUDA out of memory` 或 `no kernel image is available`

**解决**：
1. 确认你的显卡支持CUDA（Nvidia显卡都支持，AMD/Intel核显不支持）
2. 更新显卡驱动到最新版：https://www.nvidia.cn/geforce/drivers/
3. 确认PyTorch版本和CUDA版本匹配
4. 如果显卡显存小于8GB，修改 `config.json`：
```json
{
  "whisper_model": "medium",  // 用medium模型，显存占用小
  "batch_size": 1
}
```

### 问题2：cuDNN版本不匹配

**症状**：日志显示 `cuDNN version mismatch` 或 `Could not load library cudnn_ops_infer64_8.dll`

**解决**：PyTorch 2.6用的是cuDNN 9，但有些旧代码找cuDNN 8的DLL。在虚拟环境里复制DLL：

```bash
.venv\Scripts\activate
cd .venv\Lib\site-packages\torch\lib
# 复制cuDNN 9的DLL，改名为cuDNN 8的名字
copy cudnn_ops_infer64_9.dll cudnn_ops_infer64_8.dll
copy cudnn_cnn_infer64_9.dll cudnn_cnn_infer64_8.dll
copy cudnn_adv_infer64_9.dll cudnn_adv_infer64_8.dll
copy cudnn_ops_train64_9.dll cudnn_ops_train64_8.dll
copy cudnn_cnn_train64_9.dll cudnn_cnn_train64_8.dll
copy cudnn_adv_train64_9.dll cudnn_adv_train64_8.dll
copy cudnn64_9.dll cudnn64_8.dll
```

### 问题3：中文乱码导致崩溃

**症状**：处理中文歌名的歌曲时闪退，日志显示编码错误

**解决**：在 `worker.py`、`align_once.py`、`sep_once.py` 文件最顶部添加：

```python
import sys
sys.stdout.reconfigure(encoding='utf-8')
sys.stderr.reconfigure(encoding='utf-8')
```

### 问题4：模型下载失败

**症状**：首次运行时下载模型超时或失败

**解决**：用国内镜像下载，设置环境变量：

```bash
# 设置HuggingFace镜像
set HF_ENDPOINT=https://hf-mirror.com

# 然后再启动
python worker.py
```

或者手动下载模型放到缓存目录：
- Demucs模型：`C:\Users\你的用户名\.cache\torch\hub\checkpoints\`
- WhisperX模型：`C:\Users\你的用户名\.cache\whisper\`

### 问题5：显存溢出（OOM）

**症状**：处理长歌曲时闪退，日志显示 `CUDA out of memory`

**解决**：
1. 用更小的模型：`whisper_model: "medium"` 或 `"small"`
2. 关闭其他占用显存的程序（游戏、视频编辑等）
3. 增加虚拟内存（页面文件）到32GB以上
4. 处理完一首歌后自动清理显存（代码里已加 `torch.cuda.empty_cache()`）

### 问题6：多进程并发导致崩溃

**症状**：同时处理多首歌时闪退

**解决**：单路处理，一次只处理一首歌。`config.json` 里设置：
```json
{
  "batch_size": 1,
  "max_workers": 1
}
```

## 六、使用技巧

### 6.1 批量处理已有歌曲

在管理后台「AI歌词」页面，可以批量选择没有歌词的歌曲，一键入队处理。

或者用API批量入队：
```bash
curl -X POST http://NAS_IP:8083/api/separate/enqueue-missing \
  -H "Content-Type: application/json" \
  -d '{"type": "align", "limit": 500}'
```

### 6.2 查看处理进度

- 图形化界面：实时显示进度和日志
- 管理后台：「AI歌词」页面查看所有任务状态
- API查询：
```bash
curl http://NAS_IP:8083/api/separate/stats
curl http://NAS_IP:8083/api/separate/jobs?status=processing
```

### 6.3 失败任务重试

```bash
# 查看失败任务
curl http://NAS_IP:8083/api/separate/jobs?status=failed

# 重置失败任务（重新入队）
curl -X POST http://NAS_IP:8083/api/separate/jobs/69/reset
```

### 6.4 开机自动启动

把「墨墨AI工作站」快捷方式放到Windows启动文件夹：

1. 按 `Win+R`，输入 `shell:startup`，回车
2. 把桌面的「墨墨AI工作站」快捷方式复制到这个文件夹
3. 以后开机就自动启动了

### 6.5 处理完自动关机

如果想处理完所有任务后自动关机，可以在图形化界面「设置」里开启「处理完所有任务后自动关机」。

## 七、AI模型详解

### 7.1 Demucs（人声分离）

- **作用**：把一首歌分离成人声和伴奏
- **模型**：htdemucs（混合Transformer Demucs，效果最好）
- **输入**：原始歌曲（MP3/FLAC/WAV等）
- **输出**：vocals.wav（人声）+ accompaniment.wav（伴奏）+ drums.wav + bass.wav + other.wav
- **原理**：用深度学习模型训练了上万首歌，学会区分人声和乐器
- **耗时**：约歌曲时长的0.3-0.5倍（RTX 4070 Ti）

### 7.2 WhisperX（语音识别+时间轴）

- **作用**：识别人声里的歌词文字，并给出每个字的精确时间点
- **模型**：large-v2（识别最准确，显存需求大）
- **输入**：vocals.wav（分离后的人声）
- **输出**：ASR结果（每句话的文字+开始/结束时间，每个字的时间点）
- **原理**：OpenAI Whisper模型 + 强制对齐（forced alignment），逐字时间轴精度可达10毫秒
- **耗时**：约歌曲时长的0.2-0.3倍

### 7.3 歌词匹配算法（lyric_matcher.py）

- **作用**：把ASR结果（可能有错别字）和官方歌词（文字正确但无时间轴）对齐
- **算法**：Needleman-Wunsch动态规划（生物信息学里的序列比对算法）
- **代价矩阵**：
  - 同字：0分（完全匹配）
  - 同拼音：0.05分（"龙卷丰"→"龙卷风"）
  - 拼音首字母同：0.42分（模糊匹配）
  - 不匹配：1.0分
  - 删除ASR字：0.35分
  - 删除参考字：0.55分
- **输出**：官方歌词文字 + ASR时间戳（文字正确，时间精准）
- **匹配率阈值**：40%以下认为官方歌词不对，回退用ASR结果

## 八、常见问题

### Q1：没有Nvidia显卡能用吗？
**A**：能用，但非常慢（CPU处理一首歌可能要30分钟以上）。建议至少有一张GTX 1060 6GB以上的显卡。

### Q2：AMD显卡能用吗？
**A**：目前PyTorch对AMD显卡支持不好，建议用Nvidia显卡。如果只有AMD卡，可以用CPU模式，但速度很慢。

### Q3：处理一首歌要多久？
**A**：取决于显卡，RTX 4070 Ti SUPER约2-3分钟，RTX 3060约3-4分钟，GTX 1060约10-15分钟。

### Q4：处理完的歌词存在哪？
**A**：存在服务器的数据库里，和歌曲绑定。下次播放这首歌时自动加载，不需要重新处理。

### Q5：能处理MKV歌曲吗？
**A**：可以。AI工作站会先从MKV提取音频，再进行人声分离和歌词识别。但MKV通常自带字幕，建议优先用内嵌字幕，不需要AI处理。

### Q6：歌词识别准确率怎么样？
**A**：中文流行歌准确率约95%以上（配合官方歌词匹配后）。方言歌、说唱、外语歌准确率会低一些。

### Q7：处理失败了怎么办？
**A**：在管理后台查看失败原因，常见原因：
- 歌曲文件损坏 → 重新下载歌曲
- 显存不足 → 换更小的模型
- 网络问题（下载模型失败）→ 用国内镜像
- 重置失败任务后重试
