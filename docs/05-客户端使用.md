# 墨墨爱K歌 - 客户端使用指南

> 本指南讲解各种客户端的安装和使用方法，包含Apple TV、Android TV、网页端、手机遥控端。

---

## 一、客户端总览

| 客户端 | 平台 | 安装方式 | 推荐度 |
|--------|------|----------|--------|
| **tvOS客户端** | Apple TV | IPA侧载 | ⭐⭐⭐⭐⭐ 体验最佳 |
| **Android TV客户端** | Android TV/电视盒子 | APK安装 | ⭐⭐⭐⭐ 简单方便 |

| **管理后台** | 电脑浏览器 | 直接访问 | ⭐⭐⭐⭐ 管理用 |

## 二、Apple TV 客户端（tvOS）

### 2.1 安装方法

#### 方法A：Apple Configurator 2（推荐，Mac用户）

1. 在Mac App Store搜索安装「Apple Configurator 2」（免费）
2. 用USB-C线把Apple TV连接到Mac
3. 打开Apple Configurator 2，会看到你的Apple TV
4. 把 `MomoKtvTV.ipa` 文件拖到Apple TV图标上
5. 等待安装完成（约10-30秒）
6. Apple TV主屏幕就会出现「墨墨爱K歌」图标

#### 方法B：Sideloadly（Windows/Mac都可用）

1. 下载 [Sideloadly](https://sideloadly.io/)
2. 安装并打开Sideloadly
3. 用USB线连接Apple TV到电脑
4. Sideloadly里选择你的Apple TV设备
5. 输入你的Apple ID（需要开发者账号或免费账号）
6. 把 `MomoKtvTV.ipa` 拖进去
7. 点击「Start」开始安装
8. 等待完成

> ⚠️ 免费Apple ID签名的APP 7天后会过期，需要重新安装。开发者账号（99美元/年）签名的不会过期。

#### 方法C：Xcode（开发者用）

1. 用Xcode打开项目（`tvos-client/` 目录）
2. 连接Apple TV，选择设备
3. 点击运行按钮，自动编译安装

### 2.2 首次使用

1. 打开「墨墨爱K歌」
2. 输入服务器地址（如 `192.168.3.16:8083`）
3. 点击「连接」
4. 登录页面输入账号密码
5. 进入主界面，开始点歌！

> 💡 服务器地址会自动保存，下次打开自动连接。要换服务器，在设置里点「更换服务器」。

### 2.3 遥控器操作

| 播放/暂停 | 播放/暂停当前歌曲 |
| 音量+/- | 调节音量 |
| 长按返回 | 回到主页 |

### 2.5 全屏播放器

播放歌曲时按「确认」键进入全屏：

- **视频层**：MV画面（MKV/MP4）或动态背景（纯音频）
- **歌词层**：逐字高亮歌词，唱到哪个字哪个字变色
- **控制栏**：按任意键呼出，3秒无操作自动隐藏

控制栏11个按钮：

| 按钮 | 功能 |
|------|------|
| 🏠 主页 | 回到主界面 |
| 🔄 重唱 | 重新播放当前歌曲 |
| ▶️ 播放/暂停 | 播放或暂停 |
| 🎤 原唱/伴唱 | 切换音轨（MKV多音轨时） |
| ⏭️ 切歌 | 跳到下一首 |
| 📋 队列 | 查看已点歌曲 |
| 📱 扫码 | 手机扫码连接遥控 |
| 📝 歌词模式 | 单排/双排切换 |
| ⏪ 词提前 | 歌词提前0.05秒 |
| ⏩ 词延后 | 歌词延后0.05秒 |
| 🔄 复位 | 歌词时间校准归零 |
| 🎨 背景 | 切换动态背景效果 |

### 2.6 歌词调节

在手机遥控端可以调节：
- **字体颜色**：任意颜色
- **描边颜色**：任意颜色
- **描边粗细**：0-10像素
- **字体大小**：100%-300%
- **歌词位置**：上下移动
- **歌词快慢**：提前/延后，可复位

调节后实时生效，电视端立刻看到变化。

### 2.7 动态背景（14种）

纯音频歌曲（MP3/FLAC等）播放时，自动显示动态背景：

1. 流光 - 彩色光带流动
2. 水波纹 - 水面波纹扩散
3. 星空 - 闪烁的星星
4. 流星 - 流星划过
5. 星云 - 彩色星云
6. 律动环 - 随音乐跳动的圆环
7. 频谱 - 音频频谱柱状图
8. 极光 - 北极光效果
9. 细雨 - 下雨效果
10. 气泡 - 上升的气泡
11. 光束 - 旋转光束
12. 漩涡 - 漩涡效果
13. 暖焰 - 温暖火焰
14. 我的图片 - 用户上传的照片

按控制栏的「背景」按钮循环切换，也可以在手机遥控端选择。

## 三、Android TV 客户端

### 3.1 安装方法

#### 方法A：U盘安装（最简单）

1. 把 `MomoKtvTV-Android.apk` 拷到U盘
2. U盘插入Android TV/电视盒子
3. 打开文件管理器，找到APK文件
4. 点击安装（需要允许「未知来源」）
5. 安装完成，主屏幕出现「墨墨爱K歌」

#### 方法B：adb安装

1. 电脑安装 [adb工具](https://developer.android.com/studio/releases/platform-tools)
2. Android TV开启「USB调试」（设置→关于→连续点击版本号）
3. 电脑执行：
```bash
adb connect 电视IP:5555
adb install MomoKtvTV-Android.apk
```

### 3.2 使用方法

和tvOS客户端基本一致：
1. 打开应用，输入服务器地址
2. 登录后进入网页TV端
3. 用遥控器方向键导航，确认键选择
4. 返回键回退，菜单键刷新页面

> 💡 Android TV客户端本质是全屏浏览器加载网页TV端，功能和网页端完全一致。

## 四、电视网页版（零安装）

如果不想安装任何APP，直接用智能电视的浏览器访问：

```
http://你的NAS_IP:8083/tv/
```

### 4.1 支持的电视浏览器

- 索尼电视：内置浏览器
- 小米电视：投屏神器/小米浏览器
- 创维/海信/TCL：内置浏览器或安装第三方浏览器
- 任何能装浏览器的智能电视

### 4.2 使用方法

1. 打开电视浏览器
2. 输入地址 `http://NAS_IP:8083/tv/`
3. 登录后开始点歌
4. 建议把页面添加到书签，下次直接打开

> ⚠️ 网页版性能不如原生APP，旧电视可能卡顿。建议用Apple TV或Android TV原生客户端。

## 五、手机遥控端（必备）

手机遥控端是必须的，用来点歌、切歌、调歌词、当麦克风。

### 5.1 访问方式

手机连接家里WiFi，打开浏览器访问：

```
http://你的NAS_IP:8083/mobile/
```

> 💡 建议添加到手机主屏幕（Safari：分享→添加到主屏幕；Chrome：菜单→添加到主屏幕），下次直接点击图标打开，像APP一样。

### 5.2 功能一览

```
┌─────────────────────┐
│   墨墨爱K歌 - 遥控   │
├─────────────────────┤
│                     │
│     [⬆️]            │
│  [⬅️]  [OK]  [➡️]   │
│     [⬇️]            │
│                     │
│  [⏮️] [▶️] [⏭️]      │
│  [🔊+] [🔊-]        │
│  [🎤原唱/伴唱]       │
│  [📱麦克风]          │
│                     │
├─────────────────────┤
│  遥控 | 点歌 | 队列  │
└─────────────────────┘
```

### 5.3 点歌页面

- 搜索框：输入歌名/歌手搜索
- 歌曲列表：显示封面、歌名、歌手、时长
- 点歌按钮：点击加入已点队列
- 收藏按钮：点击收藏/取消收藏

### 5.4 队列页面

- 已点歌曲列表，按播放顺序排列
- 置顶按钮：把某首歌移到最前
- 删除按钮：从队列删除
- 切歌按钮：立即跳到下一首

### 5.5 手机麦克风

点击「麦克风」按钮，手机就能当麦克风唱歌！

**使用条件**：
- 手机和NAS在同一个WiFi
- 手机浏览器允许麦克风权限
- 服务端开启了麦克风功能

**延迟优化**：
- 用5GHz WiFi，不要用2.4GHz
- 手机离路由器近一些
- 在设置里调整「音频缓冲」（默认200ms，可降到100ms）

### 5.6 歌词调节

在「设置」→「歌词」里可以调节：

| 调节项 | 范围 | 说明 |
|--------|------|------|
| 字体颜色 | 任意颜色 | 未唱歌词的颜色 |
| 描边颜色 | 任意颜色 | 文字描边颜色 |
| 描边粗细 | 0-10 | 文字描边粗细 |
| 字体大小 | 100%-300% | 歌词字体大小 |
| 歌词位置 | 上下移动 | 歌词在屏幕的上下位置 |
| 歌词快慢 | -2秒~+2秒 | 歌词提前或延后 |
| 复位 | 一键 | 歌词快慢归零 |

调节后电视端实时生效。

### 5.7 氛围特效

在「氛围」页面可以发送：

- 👏 掌声 - 电视端播放掌声音效+全屏手掌刷屏
- 🥂 干杯 - 干杯音效+酒杯刷屏
- 🎉 喝彩 - 喝彩音效+笑脸刷屏
- 🤦 倒彩 - 倒彩音效+嘘声刷屏

### 5.8 祝福语

在「祝福」页面可以输入祝福语，电视端全屏滚动显示：

- 8个备选快捷语句（生日快乐、恭喜发财等）
- 自定义输入任意文字
- 字幕从右向左滚动，字号大，颜色醒目

## 六、管理后台

管理后台用来管理曲库、用户、设置等。

### 6.1 访问

电脑浏览器访问：
```
http://你的NAS_IP:8083/admin
```

默认账号：`admin`，密码是你设置的 `ADMIN_PASSWORD`（默认`admin888`）。

### 6.2 功能模块

| 模块 | 功能 |
|------|------|
| 仪表盘 | 系统状态、歌曲数、播放统计 |
| 曲库管理 | 曲库来源、扫描、歌曲编辑 |
| 用户管理 | 添加/删除用户、修改密码、权限 |
| AI歌词 | 查看AI处理任务、批量入队、失败重试 |
| 背景图片 | 上传/删除自定义背景图片 |
| 设置 | 系统设置、转码设置、缓存设置 |

### 6.3 曲库扫描

1. 进入「曲库管理」→「曲库来源」
2. 点击「添加根目录」，选择歌曲文件夹
3. 点击「扫描」开始扫描
4. 扫描过程中可以看到进度
5. 扫描完成后歌曲就可以点歌了

> 💡 每5分钟自动扫描新增歌曲，不需要手动扫描。

## 七、常见问题

### Q1：Apple TV安装后打不开？
**A**：检查：
1. IPA是否签名有效（免费账号7天过期）
2. Apple TV系统版本是否够（需要tvOS 17+）
3. 重新安装一次

### Q2：连接服务器失败？
**A**：检查：
1. 服务器地址是否正确（IP:端口，如192.168.3.16:8083）
2. 服务器容器是否在运行（`docker ps`）
3. 手机和电视是否连同一个WiFi
4. 防火墙是否开放了8083端口
5. 用手机浏览器访问 `http://NAS_IP:8083` 能不能打开

### Q3：播放没有声音？
**A**：检查：
1. 电视音量是否打开
2. 音频输出设备是否正确（HDMI/光纤/蓝牙）
3. 歌曲文件是否有音轨（用播放器在电脑上试播）
4. MKV多音轨时，切换到有声音的音轨

### Q4：原唱/伴唱切换不了？
**A**：只有MKV文件有多个音轨才能切换。MP4可能有，MP3/FLAC等纯音频只有一个音轨。用MediaInfo查看文件有几个音轨。

### Q5：歌词不同步？
**A**：
1. 在手机遥控端调节「歌词快慢」（提前/延后）
2. 调节到合适后，点击「保存」，这首歌的偏移会记住
3. AI生成的歌词通常很精准，网上下载的LRC可能不准

### Q6：手机麦克风有延迟？
**A**：
1. 用5GHz WiFi
2. 手机离路由器近
3. 在设置里降低「音频缓冲」（从200ms降到100ms）
4. 关闭手机上其他占用网络的APP

### Q7：动态背景太卡？
**A**：
1. 在设置里降低背景效果质量
2. 选择简单的背景（如星空、暖焰）
3. Apple TV 4K（2022款）性能最好，旧款可能卡

### Q8：怎么更新APP？
**A**：
- tvOS：重新下载最新IPA，用Apple Configurator重新安装（覆盖安装，设置保留）
- Android TV：下载最新APK，覆盖安装
- 网页端：刷新页面即可（服务端更新后自动生效）
