# 全国用户部署指南（115 网盘共享曲库版）

> 本指南面向通过 115 网盘挂载共享曲库的用户。不需要 GPU、不需要分离音频，
> 挂载网盘后扫描即可点歌，人声/伴奏/逐字歌词全部预生成好。

---

## 一、前置要求

- 一台 24 小时开机的设备（NAS、软路由、电脑均可），已安装 Docker
- 网络能正常访问 115 网盘
- 已拿到分发者提供的 115 分享链接（包含人声 FLAC + 伴奏 FLAC + 逐字歌词 LRC）

---

## 二、Docker Compose 部署

新建 `docker-compose.yml`：

```yaml
services:
  momo-ktv:
    image: ghcr.io/klzbw/momo-ktv:latest
    container_name: momo-ktv
    restart: unless-stopped
    network_mode: host
    ports:
      - "8083:8080"    # Web 主界面
      - "5345:5345"    # 内置 AList
    environment:
      - DATA_DIR=/data
      - PORT=8080
      - ADMIN_PASSWORD=你的管理密码
      - TZ=Asia/Shanghai
      - STARTUP_SCAN_DISABLED=1
      - ALIST_PORT=5345
    volumes:
      - ./data:/data
```

启动：

```bash
docker compose up -d
```

等待 1-2 分钟后，浏览器访问 `http://你的IP:8083`。

---

## 三、登录 115 网盘

1. 打开管理后台 `http://你的IP:8083/admin`
2. 用 `admin` + 你设置的密码登录
3. 进入「网盘管理」页面
4. 点击「添加 115 账号」
5. 页面会显示一个二维码，用手机 115 App 扫码授权
6. 授权成功后，账号状态变为「active」

> 如果分发者提供的是分享链接，在网盘管理页面选择「粘贴分享链接」，输入提取码即可挂载。

---

## 四、扫描入库

1. 在管理后台进入「曲库管理」→「网络曲库」
2. 点击「同步网盘目录」——系统会通过内置 AList 列出 115 上的歌曲目录
3. 同步完成后，点击「扫描入库」
4. 扫描过程：
   - 每首歌目录下含 `<sha>.lrc` 逐字歌词文件 → 自动读取并入库
   - `sep_status` 标记为 `done`，`align_status` 标记为 `done`
   - **不需要 GPU、不需要 WhisperX 对齐**
5. 扫描完成后，手机/TV 端即可搜索点歌

> **注意**：启动自动扫描已默认关闭（`STARTUP_SCAN_DISABLED=1`），
> 需要新增歌曲时手动到管理后台点「同步」→「扫描」即可。

## 五、逐字歌词工作原理

分发者在有 GPU 的机器上完成了以下工作：

```
原始歌曲 ──→ Demucs 分离 ──→ 人声.flac + 伴奏.flac
         ──→ WhisperX 对齐 ──→ 逐字歌词（<sha>.lrc）
                                    │
         全部上传到 115 网盘 ────────┘
                                    │
全国用户挂载 115 ──→ 扫描 ──→ 直接读取 .lrc 入库 ──→ 点唱即有逐字歌词
                                    │
                              跳过 GPU 对齐 ✓
```

每首歌在 115 上的目录结构：

```
/momo-ktv/separated/<sha16>/
  ├── <歌手>-<歌名>-人声.flac
  ├── <歌手>-<歌名>-伴奏.flac
  └── <sha16>.lrc          ← 逐字歌词，扫描时自动读取
```

## 六、自己加新歌（AI Worker 模式）

如果你想添加网盘里没有的新歌，可以挂载一台带 GPU 的 AI 工作站：

### 6.1 启动 AI Worker

在有 NVIDIA GPU 的机器上：

```bash
docker run -d --gpus all \
  -e SERVER_URL=http://你的KTV服务器IP:8083 \
  ghcr.io/klzbw/momo-ktv-worker:latest
```

Worker 会自动每 3 秒轮询服务端领取任务。

### 6.2 在管理后台排队

1. 把新歌的原始音频文件放到本地曲库目录（如 `/mv/`）
2. 管理后台「曲库管理」→ 扫描新文件
3. 找到新歌 → 点击「分离」（Demucs 分离人声/伴奏）
4. 分离完成后 → 点击「逐字对齐」（WhisperX 生成逐字歌词）
5. 完成后可运行 `GET /api/admin/export-lrc` 导出 .lrc 文件
6. 把 separated 目录（flac + lrc）上传 115，其他用户同步即可获得

### 6.3 分发者完整流程

```
改歌词（admin 后台编辑）
  ↓
调用 GET /api/admin/export-lrc（批量导出全部 .lrc）
  ↓
运行 upload-separated-to-115.js（上传 flac + lrc 到 115）
  ↓
全国用户点「同步网盘目录」→「扫描入库」
  ↓
完成！
```

## 七、常见问题

**Q: 扫描后没有逐字歌词？**
A: 检查 115 对应目录下是否有 `<sha>.lrc` 文件。没有的话说明分发者还没上传歌词。

**Q: 扫描报错或卡住？**
A: 确认 115 账号状态为 active，AList 服务正常（端口 5345 可访问）。
重启容器后等 2 分钟再点同步。

**Q: 可以同时挂载多个 115 账号吗？**
A: 可以，在网盘管理页面添加多个账号，系统会逐一同步。

**Q: 需要 GPU 吗？**
A: 播放点歌不需要 GPU。只有自己新增歌曲跑分离/对齐时才需要 GPU worker。

**Q: 歌词时间轴偏移了怎么办？**
A: 管理后台找到这首歌，用「歌词偏移」功能微调。修改后会自动回写 .lrc 文件，重新上传 115 即可。
