# 墨墨爱K歌 - 从零开始学习指南

> 本指南专为零基础小白编写，不需要任何编程经验，跟着步骤走就能搭建属于自己的家庭KTV系统。

---

## 一、这个项目是什么？

**墨墨爱K歌**是一套完整的家庭点歌系统，就像KTV包厢里的点歌机一样，但功能更强大。

### 它能做什么？

- 🎤 **点歌唱歌**：用遥控器/手机点歌，电视上播放MV和歌词
- 📺 **多端支持**：Apple TV、Android TV、网页端、手机遥控端
- 🎵 **海量曲库**：支持MKV、MP4、MP3、FLAC、WAV等各种格式
- ✨ **AI歌词精准化**：自动为没有歌词的歌曲生成逐字同步歌词
- 🎨 **动态背景**：纯音频歌曲自动显示水波纹、星空、极光等动态背景
- 📱 **手机麦克风**：用手机当麦克风唱歌（同WiFi下）

### 它由哪几部分组成？

想象一个KTV包厢：

```
┌─────────────────────────────────────────────────┐
│                    你的家庭网络                     │
│                                                    │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │  电视端    │    │  服务器    │    │  手机端    │  │
│  │ (点歌播放) │◄──►│ (曲库管理) │◄──►│ (遥控点歌) │  │
│  └──────────┘    └──────────┘    └──────────┘  │
│                       │                            │
│                  ┌────▼─────┐                      │
│                  │ AI工作站  │                      │
│                  │(歌词生成) │                      │
│                  └──────────┘                      │
└─────────────────────────────────────────────────┘
```

| 组件 | 作用 | 运行在哪 |
|------|------|----------|
| **服务器** | 管理曲库、提供API、转码播放 | 飞牛NAS / 电脑 / 树莓派 |
| **电视端** | 点歌界面、播放MV、显示歌词 | Apple TV / Android TV / 浏览器 |
| **手机端** | 遥控器、点歌、麦克风 | 手机浏览器 |
| **AI工作站** | 自动生成精准歌词 | 有Nvidia显卡的Windows电脑 |

## 二、需要准备什么？

### 最低配置（能跑起来）

| 设备 | 要求 | 说明 |
|------|------|------|
| 服务器 | 飞牛NAS / 任意电脑 | 存放歌曲，运行服务端 |
| 播放设备 | Apple TV / Android TV / 智能电视浏览器 | 看电视唱歌 |
| 网络 | 家里的WiFi/有线网络 | 所有设备连同一个路由器 |
| 歌曲 | 至少1首MKV/MP4/MP3 | 没有歌就没法唱啦 |

### 推荐配置（体验更好）

- **服务器**：飞牛NAS（24小时开机，省电静音）
- **播放设备**：Apple TV 4K（体验最流畅）或 Android TV 盒子
- **AI工作站**：有Nvidia显卡的Windows电脑（RTX 3060以上，自动生成歌词）
- **曲库**：1000首以上歌曲（MKV格式最佳，带MV和字幕）

## 三、5分钟快速上手（最简单的方式）

如果你有一台飞牛NAS，跟着这5步走：

### 第1步：安装服务端（飞牛NAS）

1. 打开飞牛NAS的「应用商店」
2. 搜索「墨墨爱K歌」
3. 点击安装，等待完成
4. 安装完成后，打开应用，按照引导设置曲库目录

> 没有飞牛NAS？看《03-服务端部署.md》，里面有电脑Docker部署教程。

### 第2步：添加歌曲

1. 把你的歌曲文件（MKV/MP4/MP3等）放到NAS的某个文件夹
2. 打开墨墨爱K歌的「管理后台」（浏览器访问 `http://NAS_IP:8083/admin`）
3. 进入「曲库管理」→「曲库来源」
4. 添加你的歌曲文件夹，点击「扫描」
5. 等待扫描完成（1000首歌大约1-2分钟）

### 第3步：电视端点歌

**方式A：Apple TV**
- 安装 `MomoKtvTV.ipa`（用Apple Configurator或侧载工具）
- 打开应用，输入服务器地址（如 `192.168.3.16:8083`）
- 登录后开始点歌

**方式B：Android TV**
- 安装 `MomoKtvTV-Android.apk`（U盘安装或adb install）
- 打开应用，输入服务器地址
- 登录后开始点歌

**方式C：智能电视浏览器**
- 打开电视浏览器，访问 `http://NAS_IP:8083/tv/`
- 登录后开始点歌（最简单，不需要安装任何东西）

### 第4步：手机当遥控器

1. 手机连接家里的WiFi
2. 打开手机浏览器，访问 `http://NAS_IP:8083/mobile/`
3. 登录后就是遥控器界面，可以点歌、切歌、调音量
4. 点击「麦克风」按钮，手机就能当麦克风唱歌！

### 第5步：开始唱歌！

- 用遥控器或手机搜索歌曲，点击「点歌」
- 歌曲会加入已点队列，按顺序播放
- 唱歌时可以切换原唱/伴唱、调音量、切歌

## 四、常见问题（小白必看）

### Q1：我完全不懂技术，能搞定吗？
**A**：能！本指南就是为小白写的。只要会用电脑、会点鼠标，跟着步骤走就行。遇到问题看《常见问题》章节，90%的问题都有答案。

### Q2：没有NAS，用普通电脑能跑吗？
**A**：能！电脑安装Docker后，运行一条命令就能启动服务端。看《03-服务端部署.md》的「电脑Docker部署」章节。

### Q3：歌曲从哪里来？
**A**：你可以从网上下载MKV格式的KTV歌曲（带MV和字幕），也可以用普通的MP3/FLAC音频文件。纯音频歌曲会自动显示动态背景和歌词。

### Q4：Apple TV怎么安装IPA？
**A**：用Apple Configurator 2（Mac免费软件）或者侧载工具（如Sideloadly）。把Apple TV用USB线连到电脑，拖入IPA文件即可安装。详细步骤看《05-客户端使用.md》。

### Q5：手机麦克风有延迟怎么办？
**A**：确保手机和NAS连同一个WiFi，离路由器近一些。延迟通常在100-300毫秒，唱歌时基本感觉不到。如果延迟大，可以在手机端设置里调整「音频缓冲」。

### Q6：AI歌词精准化是什么？需要吗？
**A**：AI歌词精准化是用人工智能为没有歌词的歌曲自动生成逐字同步歌词（就像KTV里那样，唱到哪个字哪个字变色）。如果你大部分歌曲是MKV格式（自带字幕），就不需要。如果有很多MP3/FLAC没有歌词，建议配置AI工作站。

## 六、项目文件结构（了解即可）

```
momo-ktv/
├── app/                          # 服务端 + 网页端
│   └── docker/
│       ├── server/               # Node.js 服务端（API、曲库、转码）
│       │   └── index.js         # 主程序（90个API接口）
│       └── web/                  # 网页端
│           ├── tv/               # 电视端点歌界面
│           ├── mobile/           # 手机遥控端
│           ├── admin/            # 管理后台
│           └── mic/              # 手机麦克风端
├── tvos-client/                  # Apple TV 客户端（Swift/SwiftUI）
│   └── MomoKtvTV/
│       ├── ContentView.swift     # 主界面
│       ├── FullPlayerView.swift  # 全屏播放器
│       ├── LyricsView.swift      # 歌词显示
│       └── AudioBackgroundView.swift  # 动态背景
├── android-tv-client/            # Android TV 客户端（Kotlin + WebView）
│   └── app/src/main/java/com/momo/ktv/tv/
│       ├── MainActivity.kt       # 全屏WebView主界面
│       └── ServerConfigActivity.kt  # 服务器配置页
├── ai-worker/                    # AI歌词精准化工作站（Python）
│   ├── worker.py                 # 主程序（从服务端领任务）
│   ├── align_once.py             # 单首歌歌词对齐
│   ├── lyric_matcher.py          # 中文歌词匹配算法
│   └── sep_once.py               # 人声分离（Demucs）
├── docs/                         # 学习文档（你正在看的）
└── README.md                     # 项目简介
```
