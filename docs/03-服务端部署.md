# 墨墨爱K歌 - 服务端部署指南

> 本指南详细讲解如何在飞牛NAS、电脑、树莓派等设备上部署服务端，包含独立显卡支持。

---

## 一、部署方式对比

| 部署方式 | 难度 | 优点 | 缺点 | 推荐人群 |
|----------|------|------|------|----------|
| **飞牛NAS应用商店** | ⭐ 最简单 | 一键安装，24小时开机，省电静音 | 功能可能不是最新 | 小白首选 |
| **飞牛NAS Docker** | ⭐⭐ 简单 | 功能最新，可自定义 | 需要懂一点Docker | 有NAS的用户 |
| **电脑Docker** | ⭐⭐ 简单 | 性能好，可加独立显卡 | 电脑要一直开着 | 有闲置电脑的用户 |
| **电脑直接运行** | ⭐⭐⭐ 中等 | 性能最好，调试方便 | 需要安装Node.js环境 | 开发者 |
| **树莓派** | ⭐⭐⭐ 中等 | 省电，体积小 | 性能弱，转码慢 | 极客玩家 |

## 二、飞牛NAS部署（推荐）

### 方式A：应用商店一键安装（最简单）

1. 打开飞牛NAS的「应用商店」
2. 搜索「墨墨爱K歌」
3. 点击「安装」
4. 等待安装完成（约1-2分钟）
5. 安装完成后，点击「打开」
6. 按照引导界面设置：
   - 曲库目录：选择你存放歌曲的文件夹
   - 端口：默认8083（可以改）
   - 管理员密码：设置一个密码
7. 点击「完成」，服务端就启动了！

> 访问地址：`http://你的NAS_IP:8083`
> 管理后台：`http://你的NAS_IP:8083/admin`

### 方式B：Docker手动部署（功能最新）

如果应用商店的版本不是最新，可以用Docker手动部署。

#### 第1步：安装Docker

飞牛NAS系统自带Docker，在「应用商店」搜索「Docker」安装即可。

#### 第2步：创建文件夹

在文件管理器里创建以下文件夹：

```
/vol1/docker/momo-ktv/          # 应用配置目录
/vol1/music/                      # 歌曲目录（你自己的曲库存这里）
```

#### 第3步：创建docker-compose.yml

在 `/vol1/docker/momo-ktv/` 目录下创建 `docker-compose.yml` 文件，内容如下：

```yaml
services:
  momo-ktv:
    image: ghcr.io/klzbw/momo-ktv:latest
    container_name: momo-ktv
    restart: unless-stopped
    ports:
      - "8083:8080"
    environment:
      - TZ=Asia/Shanghai
      - PORT=8080
      - DATA_DIR=/data
      - MV_DIR=/mv
      - ADMIN_PASSWORD=admin888  # 改成你自己的密码
      - AUTO_SCAN_MIN=5           # 每5分钟自动扫描新歌
    volumes:
      - /vol1/docker/momo-ktv:/data    # 数据库和配置
      - /vol1/music:/mv/library1        # 你的歌曲目录
    # 如果有独立显卡，取消下面的注释（需要NVIDIA Container Toolkit）
    # deploy:
    #   resources:
    #     reservations:
    #       devices:
    #         - driver: nvidia
    #           count: all
    #           capabilities: [gpu]
```

#### 第4步：启动容器

SSH连接到NAS，执行：

```bash
cd /vol1/docker/momo-ktv
docker-compose pull    # 拉取最新镜像
docker-compose up -d   # 启动容器
```

#### 第5步：验证

浏览器访问 `http://你的NAS_IP:8083`，能看到登录页面就成功了！

## 三、电脑Docker部署（Windows/Mac/Linux）

### 第1步：安装Docker

- **Windows**：下载安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- **Mac**：下载安装 Docker Desktop（Intel芯片选x86，M系列选ARM）
- **Linux**：`curl -fsSL https://get.docker.com | sh`

安装完成后，启动Docker Desktop。

### 第2步：创建文件夹

在电脑上创建：
```
D:\momo-ktv\data\     # 数据库和配置
D:\momo-ktv\music\    # 歌曲目录
```

### 第3步：创建docker-compose.yml

在 `D:\momo-ktv\` 目录下创建 `docker-compose.yml`：

```yaml
services:
  momo-ktv:
    image: ghcr.io/klzbw/momo-ktv:latest
    container_name: momo-ktv
    restart: unless-stopped
    ports:
      - "8083:8080"
    environment:
      - TZ=Asia/Shanghai
      - PORT=8080
      - DATA_DIR=/data
      - MV_DIR=/mv
      - ADMIN_PASSWORD=admin888
    volumes:
      - D:\momo-ktv\data:/data
      - D:\momo-ktv\music:/mv/library1
    # Windows有Nvidia显卡的话，取消下面注释
    # deploy:
    #   resources:
    #     reservations:
    #       devices:
    #         - driver: nvidia
    #           count: all
    #           capabilities: [gpu]
```

### 第4步：启动

打开命令行（CMD或PowerShell），执行：

```bash
cd D:\momo-ktv
docker compose pull
docker compose up -d
```

### 第5步：验证

浏览器访问 `http://localhost:8083`，能看到登录页面就成功了！

> 家里其他设备访问：`http://你电脑的局域网IP:8083`
> 查看电脑局域网IP：Windows执行 `ipconfig`，找「IPv4地址」

## 四、独立显卡支持（NVENC硬件转码）

如果你的服务器有Nvidia独立显卡，可以开启硬件转码，大幅降低CPU占用，转码速度更快。

### 4.1 飞牛NAS支持独立显卡吗？

飞牛NAS本身通常**没有独立显卡**（NAS主要是存储，不是计算）。但有两种方式可以用显卡：

#### 方式A：NAS PCIe插槽插显卡

部分飞牛NAS型号有PCIe插槽，可以插一张半高显卡（如GTX 1650 Low Profile）。

**步骤**：
1. 确认你的NAS有PCIe插槽
2. 购买一张半高Nvidia显卡（GTX 1650 LP约800元，功耗75W不需要额外供电）
3. 打开机箱，插入显卡
4. 在飞牛系统里安装NVIDIA驱动
5. 安装NVIDIA Container Toolkit
6. docker-compose.yml里添加GPU配置（见上面的注释部分）
7. 重启容器

> ⚠️ 注意：不是所有飞牛NAS都有PCIe插槽，买之前先确认型号。NAS电源功率可能不够，需要确认电源额定功率。

#### 方式B：用另一台有显卡的电脑做AI工作站

这是**推荐方案**！NAS只做存储和服务端，AI歌词生成放在有显卡的Windows电脑上运行。

- NAS：24小时开机，跑服务端（不需要显卡）
- 电脑：需要生成歌词时开机，跑完关机（省电）
- AI工作站：从服务端领取任务，处理完上传结果

详细配置看《04-AI工作站.md》。

### 4.2 电脑Docker开启GPU支持

#### Windows（WSL2后端）

1. 安装最新的[NVIDIA显卡驱动](https://www.nvidia.cn/geforce/drivers/)
2. Docker Desktop设置里启用「Use the WSL 2 based engine」
3. docker-compose.yml里取消GPU部分的注释
4. 重启容器

验证GPU是否生效：
```bash
docker exec momo-ktv nvidia-smi
```
能看到显卡信息就说明成功了！

#### Linux

1. 安装NVIDIA驱动
2. 安装[NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html)：
```bash
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list
sudo apt-get update
sudo apt-get install -y nvidia-container-toolkit
sudo systemctl restart docker
```
3. docker-compose.yml里取消GPU部分的注释
4. 重启容器

## 五、曲库配置

### 5.1 支持的歌曲格式

| 格式 | 视频 | 字幕 | 原唱/伴唱 | 推荐度 |
|------|------|------|----------|--------|
| **MKV** | ✅ | ✅ 内嵌多字幕 | ✅ 多音轨 | ⭐⭐⭐⭐⭐ 最佳 |
| **MP4** | ✅ | ⚠️ 可能有 | ⚠️ 可能有 | ⭐⭐⭐⭐ |
| **MP3** | ❌ | ❌ | ❌ | ⭐⭐⭐ 需AI生成歌词 |
| **FLAC** | ❌ | ❌ | ❌ | ⭐⭐⭐ 无损音质，需AI歌词 |
| **WAV** | ❌ | ❌ | ❌ | ⭐⭐ 文件大 |
| **APE** | ❌ | ❌ | ❌ | ⭐⭐ |
| **CUE** | ❌ | ❌ | ❌ | ⭐ 整轨文件，需切割 |

### 5.2 文件命名规范

扫描器会从文件名提取歌名和歌手，推荐格式：

```
歌手 - 歌名.mp3
歌手 - 歌名 [MV].mkv
歌手 - 歌名 (演唱会).mkv
```

示例：
```
邓紫棋 - 龙卷风.mkv
周杰伦 - 晴天.mp3
陈奕迅 - 十年 [Live].flac
```

> 如果文件名不规范也没关系，可以在管理后台手动编辑歌名和歌手。

### 5.3 添加曲库

1. 打开管理后台 `http://NAS_IP:8083/admin`
2. 登录（用户名admin，密码是你设置的ADMIN_PASSWORD）
3. 进入「曲库管理」→「曲库来源」
4. 点击「添加根目录」
5. 选择你的歌曲文件夹（容器内路径，如 `/mv/library1`）
6. 点击「扫描」
7. 等待扫描完成（1000首约1-2分钟，10000首约10-15分钟）

### 5.4 多曲库目录

可以添加多个曲库目录，比如：
- `/mv/library1` → 经典老歌
- `/mv/library2` → 现代流行
- `/mv/library3` → 外语歌曲

在docker-compose.yml里添加多个volume挂载即可：

```yaml
volumes:
  - /vol1/docker/momo-ktv:/data
  - /vol1/music/classic:/mv/library1      # 经典老歌
  - /vol1/music/pop:/mv/library2           # 现代流行
  - /vol1/music/foreign:/mv/library3       # 外语歌曲
```

## 六、常用管理操作

### 6.1 查看容器状态

```bash
docker ps | grep momo-ktv
```

### 6.2 查看日志

```bash
docker logs momo-ktv --tail 50    # 最近50行
docker logs -f momo-ktv            # 实时跟踪日志
```

### 6.3 重启容器

```bash
docker restart momo-ktv
```

### 6.4 更新到最新版本

```bash
cd /vol1/docker/momo-ktv
docker-compose pull
docker-compose up -d
```

### 6.5 备份数据

数据库文件在 `/vol1/docker/momo-ktv/momo.db`，复制这个文件就完成备份了。

```bash
cp /vol1/docker/momo-ktv/momo.db /vol1/backup/momo-$(date +%Y%m%d).db
```

### 6.6 恢复数据

```bash
docker stop momo-ktv
cp /vol1/backup/momo-20240101.db /vol1/docker/momo-ktv/momo.db
docker start momo-ktv
```

## 七、常见问题

### Q1：容器启动了但访问不了？
**A**：检查以下几点：
1. 端口映射是否正确（默认8083:8080）
2. 防火墙是否开放了8083端口
3. 容器是否真的在运行：`docker ps`
4. 查看日志有没有报错：`docker logs momo-ktv`

### Q2：扫描不到歌曲？
**A**：检查：
1. 歌曲文件格式是否支持（MKV/MP4/MP3/FLAC等）
2. volume挂载路径是否正确（容器内能看到文件吗？）
3. 执行 `docker exec momo-ktv ls /mv/library1` 看能不能列出歌曲
4. 查看扫描日志：`docker logs momo-ktv | grep -i scan`

### Q3：播放卡顿？
**A**：可能原因：
1. 网络带宽不够（用有线网络，不要用WiFi）
2. NAS性能太弱（转码耗CPU，建议用有显卡的设备）
3. 歌曲码率太高（4K视频转码很吃性能）
4. 开启硬件转码（NVENC）可以大幅改善

### Q4：原唱/伴唱切换不了？
**A**：只有MKV文件有多个音轨才能切换。检查：
1. 文件是不是MKV格式
2. MKV里是不是有2个音轨（用MediaInfo查看）
3. 第1轨通常是原唱，第2轨是伴唱

### Q5：歌词显示乱码？
**A**：可能是LRC文件编码不对。在管理后台重新获取歌词，或者用AI工作站重新生成精准歌词。

### Q6：怎么修改管理员密码？
**A**：编辑docker-compose.yml里的 `ADMIN_PASSWORD`，然后重启容器：
```bash
docker-compose up -d
```
