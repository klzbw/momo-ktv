# 墨墨爱K歌 - PC工具箱 使用说明

## 📦 工具箱简介

这是一个集成了项目开发中所有常用工具的可视化应用程序，无需记忆命令行，点击按钮即可完成操作。

**7大功能模块：**
1. 🐙 **GitHub管理** - 提交代码、触发构建、下载IPA/APK
2. 📁 **文件工具** - 查找替换、批量重命名
3. 🔗 **SSH远程** - 连接NAS/PC、执行命令、部署Docker
4. 🐳 **Docker管理** - 容器管理、镜像管理、查看日志
5. 🤖 **AI工作站** - 环境检测、一键安装、启动Worker
6. 🔨 **构建工具** - 本地/远程构建Android APK、Docker镜像
7. 📚 **命令学习** - 所有命令的原理和代码示例

---

## 🚀 快速开始

### 1. 环境要求
- Windows 10/11（64位）
- Python 3.10 或更高版本
- 网络连接

### 2. 安装Python（如果没有）
1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.10+
3. 安装时**务必勾选** "Add Python to PATH"
4. 安装完成后，打开命令行输入 `python --version` 验证

### 3. 启动工具箱
1. 双击 `启动工具箱.bat`
2. 首次运行会自动安装依赖（requests、paramiko）
3. 等待工具箱窗口打开

> 如果启动失败，先双击 `安装依赖.bat` 手动安装

## 📖 各模块详细说明

### 🐙 1. GitHub管理

**功能：** 管理GitHub仓库，触发构建，下载产物

**配置步骤：**
1. 在「Token」输入框填入你的GitHub Personal Access Token
   - 获取地址：https://github.com/settings/tokens
   - 需要勾选 `repo` 权限
2. 「仓库」默认 `klzbw/momo-ktv`，可修改
3. 「分支」默认 `main`
4. 点击「保存」

**常用操作：**
- **获取最新Commit**：查看当前分支最新提交信息
- **查看构建状态**：查看最近10次构建的状态（成功/失败/进行中）
- **触发Docker构建**：触发服务端Docker镜像构建
- **触发tvOS构建**：触发Apple TV客户端IPA构建
- **触发Android构建**：触发Android TV客户端APK构建
- **下载最新tvOS IPA**：自动找到最近成功的构建并下载IPA
- **下载最新Android APK**：自动找到最近成功的构建并下载APK

**下载的文件位置：** `tools/PC工具箱/downloads/`

### 📁 2. 文件工具

**功能：** 批量查找替换文件内容、批量重命名文件

#### 查找替换
1. 「目录」选择要搜索的文件夹
2. 「查找」输入要找的文字
3. 「替换为」输入替换后的文字（只查找不替换可留空）
4. 「文件类型」指定搜索哪些文件（默认：.swift,.js,.html,.css,.py,.kt,.xml,.yml,.md）
5. 点击「查找」预览结果，确认后点击「替换」

> ⚠️ 替换操作不可撤销，建议先备份重要文件！

#### 批量重命名
1. 「目录」选择要重命名的文件夹
2. 「查找」输入文件名中要替换的文字
3. 「替换为」输入新文字
4. 点击「预览」查看效果
5. 确认后点击「执行」

---

### 🔗 3. SSH远程

**功能：** 通过SSH连接到NAS或远程电脑，执行命令

**配置步骤：**
1. 「主机」输入NAS的IP地址（如 192.168.3.16）
2. 「端口」默认22
3. 「用户」输入SSH用户名
4. 「密码」输入SSH密码
5. 点击「保存配置」
6. 点击「测试连接」验证

**快捷命令：**
- **查看容器状态**：`docker ps -a` 查看所有Docker容器
- **查看momo-ktv日志**：查看服务端最近50行日志
- **重启momo-ktv**：重启服务端容器
- **更新镜像并重启**：拉取最新镜像并重启服务
- **磁盘空间**：`df -h` 查看磁盘使用情况
- **系统资源**：`free -h && uptime` 查看内存和运行时间
- **曲库文件数**：统计曲库中有多少首歌

**自定义命令：**
在底部输入框输入任意Linux命令，点击「执行」

> 💡 涉及docker和/vol目录的命令会自动加sudo

---

### 🐳 4. Docker管理

**功能：** 管理本地和远程（NAS）的Docker容器和镜像

**本地Docker（你的电脑）：**
- **容器列表**：查看本地所有容器
- **镜像列表**：查看本地所有镜像
- **系统资源**：查看Docker磁盘使用
- **清理无用镜像**：删除未使用的镜像释放空间

**远程Docker（NAS）：**
- **容器列表**：查看NAS上所有容器
- **momo-ktv日志**：查看服务端日志
- **重启/停止/启动**：控制momo-ktv容器
- **拉取最新镜像**：从GitHub Container Registry拉取最新镜像
- **更新并重启**：一键更新到最新版本
- **删除旧容器**：强制删除容器（谨慎使用）

**自定义Docker命令：**
在底部输入框输入Docker命令，选择「本地执行」或「远程执行」

### 🤖 5. AI工作站

**功能：** 管理AI歌词精准化工作站（Demucs人声分离 + WhisperX语音识别）

**配置步骤：**
1. 「服务器」输入服务端地址（如 http://192.168.3.16:8083）
2. 「设备」选择 `cuda`（有NVIDIA显卡）或 `cpu`
3. 「Worker目录」选择项目中的 `ai-worker` 文件夹

**操作流程：**

#### 第一步：环境检测
点击「环境检测」，查看：
- Python版本
- 是否在虚拟环境中
- PyTorch版本
- CUDA是否可用
- 显卡型号和显存
- Demucs是否安装
- WhisperX是否安装

#### 第二步：一键安装环境
如果检测显示未安装，点击「一键安装环境」：
1. 自动创建Python虚拟环境（.venv）
2. 安装PyTorch 2.6.0 + CUDA 12.4
3. 安装Demucs + WhisperX
4. 安装其他依赖

> ⏱️ 预计需要10-20分钟，取决于网络速度
> 💡 推荐使用NVIDIA RTX 3060 12GB以上显卡

#### 第三步：下载AI模型
点击「下载AI模型」：
- Demucs htdemucs 模型（人声分离）
- WhisperX large-v2 模型（语音识别）
- 自动使用国内镜像 hf-mirror.com 加速

> ⏱️ 模型约3-5GB，首次下载需要时间

#### 第四步：启动Worker
点击「启动Worker」：
- 自动写入配置文件（worker_config.json）
- 启动Worker进程，连接到服务端
- 实时显示Worker日志
- 服务端有歌词精准化任务时自动处理

**停止Worker：** 点击「停止Worker」

### 🔨 6. 构建工具

**功能：** 本地或远程构建应用

**本地构建：**
- **构建Android APK**：在本地用Gradle构建Android TV客户端
  - 需要安装Android SDK和JDK 17
  - 输出位置：`android-tv-client/app/build/outputs/apk/release/`
- **构建Docker镜像**：在本地构建服务端Docker镜像
  - 需要安装Docker Desktop
  - 镜像名：`momo-ktv:local`

**远程构建（推荐）：**
通过GitHub Actions在云端构建，无需本地环境：
- 触发Docker/tvOS/Android构建
- 查看构建状态
- 自动轮询（每30秒刷新一次）

> 💡 推荐使用远程构建，稳定可靠，不占用本地资源

## ❓ 常见问题

### Q1: 启动时提示"未检测到Python"
**A:** 请先安装Python 3.10+，安装时务必勾选"Add Python to PATH"。安装完成后重启电脑。

### Q2: SSH连接失败
**A:** 检查：
1. NAS的IP地址是否正确
2. SSH服务是否开启（飞牛NAS：控制面板→终端→启用SSH）
3. 用户名和密码是否正确
4. 端口是否为22（有些NAS默认端口不同）

### Q3: GitHub操作返回401错误
**A:** Token无效或过期。请重新生成GitHub Personal Access Token，确保勾选了`repo`权限。

### Q4: AI工作站检测不到CUDA
**A:** 检查：
1. 是否安装了NVIDIA显卡驱动
2. 显卡是否支持CUDA（GTX 10系及以上）
3. PyTorch是否安装了CUDA版本（运行`安装依赖.bat`）
4. 显存是否足够（推荐8GB以上）

### Q5: 下载IPA/APK失败
**A:** 检查：
1. GitHub Token是否有`actions:read`权限
2. 是否有最近成功的构建（先触发构建并等待完成）
3. 网络是否能访问GitHub

### Q6: 工具箱界面显示乱码
**A:** Windows系统区域设置问题。解决方案：
1. 控制面板→区域→管理→更改系统区域设置
2. 勾选"Beta版：使用Unicode UTF-8提供全球语言支持"
3. 重启电脑
