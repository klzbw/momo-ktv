# 墨墨爱K歌 - tvOS IPA调试工具箱 使用说明

## 📦 工具箱简介

这是一个专门用于tvOS客户端IPA调试和修改的可视化工具，集成了代码编辑、控件调试、参数调整、GitHub互通、IPA管理等功能。

**8大功能模块：**
1. ⚙️ **配置** - GitHub Token、本地源码目录配置
2. 🐙 **GitHub互通** - Commit历史、对比、源码下载、触发构建、下载IPA
3. 📦 **IPA管理** - IPA解析、解压、Info.plist查看、图标提取、安装指引
4. 🎛️ **控件调试** - 搜索控件、查看位置、快速修改
5. 🎨 **参数调整** - 全局字体、颜色主题、焦点效果、布局参数、动画参数
6. 📝 **代码编辑** - 带行号的代码编辑器、查找替换、撤销
7. ⚡ **快速修改** - 常用修改模板、自定义正则替换
8. 🚀 **构建提交** - 扫描本地修改、提交GitHub、触发tvOS构建

---

## 🚀 快速开始

### 1. 环境要求
- Windows 10/11（64位）
- Python 3.10 或更高版本
- GitHub Personal Access Token（需要repo权限）
- 本地tvOS源码（可选，可从GitHub下载）

### 2. 安装Python
1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.10+
3. 安装时**务必勾选** "Add Python to PATH"

### 3. 启动工具箱
1. 双击 `启动工具箱.bat`
2. 首次运行自动安装依赖（requests）
3. 等待工具箱窗口打开

## 📖 各模块详细说明

### ⚙️ 1. 配置

**第一步：配置GitHub**
1. 在「Token」输入框填入GitHub Personal Access Token
   - 获取地址：https://github.com/settings/tokens
   - 点击「Generate new token」
   - 勾选 `repo` 权限（全部仓库权限）
   - 生成后复制Token（只显示一次！）
2. 「仓库」默认 `klzbw/momo-ktv`
3. 「分支」默认 `main`
4. 点击「保存配置」
5. 点击「测试GitHub连接」验证

**第二步：配置本地源码（可选）**
1. 「本地源码目录」选择项目根目录（包含tvos-client文件夹）
2. 「tvOS源码路径」默认 `tvos-client/JunyaoKtvTV`
3. 点击「加载本地源码」将所有Swift文件加载到内存

> 💡 如果没有本地源码，可以在「GitHub互通」标签页下载最新源码

---

### 🐙 2. GitHub互通

**获取Commit历史**
- 点击「获取Commit历史」
- 显示最近20条commit，包含SHA、信息、作者、日期

**下载源码**
- 「下载最新源码」：下载当前分支的完整源码ZIP
- 「下载指定commit源码」：输入commit SHA，下载该版本源码

**对比两个commit**
- 点击「对比两个commit」
- 输入旧commit和新commit的SHA
- 显示变更文件列表、新增/删除行数

**触发构建**
- 「触发tvOS构建」：触发GitHub Actions构建IPA
- 「查看构建状态」：查看最近10次构建状态
- 「下载最新IPA」：自动找到最近成功的构建并下载IPA

---

### 📦 3. IPA管理

**解析IPA信息**
1. 点击「浏览」选择IPA文件，或点击「从GitHub下载」
2. 点击「解析IPA信息」
3. 显示：文件名、大小、Bundle ID、应用名称、版本号、构建号、最低系统、文件统计

**解压IPA**
- 点击「解压IPA」，将IPA解压到同目录的_extracted文件夹

**查看Info.plist**
- 点击「查看Info.plist」，显示完整的应用配置信息（JSON格式）

**提取图标**
- 点击「提取图标」，将IPA中的所有图片资源提取到icons_extracted文件夹

**安装指引**
- 底部显示Windows安装tvOS IPA的4种方法：
  1. Apple Configurator（需要Mac）
  2. Xcode（需要Mac）
  3. 第三方工具（爱思助手/3uTools，Windows可用）
  4. 命令行（需要Mac + Xcode）

---

### 🎛️ 4. 控件调试

**搜索控件**
1. 选择Swift文件（点击「刷新文件列表」）
2. 选择控件类型：Button、Text、Image、TextField、ScrollView、List、VStack、HStack、ZStack、所有
3. 可选输入「包含文字」过滤
4. 点击「搜索」
5. 列表显示找到的控件：行号、类型、内容

**查看控件位置**
- 双击列表中的控件，显示该控件前后5行的代码上下文

**快速修改**
- 选择控件后，在底部设置：
  - 字体大小（如20）
  - 字体粗细（regular/bold/semibold/heavy/light）
  - 前景色（如.white、Color(hex: 0xff0000)）
- 点击「应用修改」记录修改（演示模式，实际修改请用代码编辑）

---

### 🎨 5. 参数调整

**全局字体调整**
1. 拖动滑块设置放大倍数（0.5x - 3.0x）
2. 点击「预览所有字体大小」查看当前项目使用的字体大小及放大后的值
3. 点击「应用全局字体放大」批量修改所有Swift文件中的字体大小

**颜色主题调整**
- 设置背景色、文字色、强调色（十六进制，如0x1a1a2e）
- 点击「应用颜色主题」（需手动修改Theme.swift）

**焦点效果调整**
- 焦点框padding（0-10px）
- 缩放比例（1.0-1.5）
- 是否禁用系统焦点效果
- 点击「应用焦点设置」（需修改FullPages.swift的TVTightButton）

**布局参数调整**
- 键盘按键宽度/高度（30-150）
- 行高（20-200）
- 点击「应用布局参数」

**动画参数调整**
- 动画时长（0-2秒）
- 控件隐藏延迟（0-30秒）
- 点击「应用动画参数」

---

### 📝 6. 代码编辑

**功能**
- 带行号显示的代码编辑器
- 深色主题（黑底白字）
- 查找/替换/全部替换
- 撤销功能
- 保存到本地文件

**操作**
1. 选择文件（点击「刷新」）
2. 在编辑器中修改代码
3. 按Ctrl+F查找，或使用顶部查找替换栏
4. 点击「保存」写入本地文件

---

### ⚡ 7. 快速修改

**常用模板（8个）**
1. 全局字体放大1.5倍
2. 键盘按键加大1.2倍
3. 禁用所有系统焦点效果
4. 歌曲行高加大到80
5. 歌词字体加大到40
6. 控件隐藏延迟改为5秒
7. 背景色改为深色
8. 添加TVTightButton组件

**自定义修改（正则表达式）**
1. 输入查找正则表达式（如 `\.system\(size:\s*(\d+)`）
2. 输入替换内容（支持分组引用，如 `.system(size: \1`）
3. 选择目标文件（所有Swift文件或指定文件）
4. 点击「预览匹配数」查看将修改多少处
5. 确认后点击「执行替换」

> 💡 正则表达式语法参考：
> - `\d+` 匹配一个或多个数字
> - `\s*` 匹配零个或多个空白
> - `(...)` 捕获分组，替换时用 `\1` `\2` 引用
> - `.` 匹配任意字符

---

### 🚀 8. 构建提交

**扫描本地修改**
- 点击「扫描本地修改」
- 显示所有Swift文件，标记最近1小时内修改的文件

**提交到GitHub**
1. 填写提交标题（如 `fix: 调整键盘按键大小`）
2. 填写详细说明
3. 点击「提交到GitHub」
4. 自动将所有Swift文件提交到GitHub

**提交并触发构建**
- 点击「提交并触发tvOS构建」
- 先提交代码，3秒后自动触发tvOS IPA构建
- 构建完成后可在「GitHub互通」下载IPA

## ❓ 常见问题

### Q1: 提示"未检测到Python"
**A:** 安装Python 3.10+，安装时勾选"Add Python to PATH"，安装后重启电脑。

### Q2: GitHub操作返回401
**A:** Token无效或过期。重新生成Token，确保勾选了`repo`权限。

### Q3: 加载本地源码后文件列表为空
**A:** 检查「本地源码目录」是否正确，该目录下应包含`tvos-client/JunyaoKtvTV/`文件夹。

### Q4: 提交到GitHub失败
**A:** 检查：
1. Token是否有`repo`权限
2. 网络是否能访问GitHub
3. 分支是否存在

### Q5: 正则替换没有效果
**A:** 检查正则表达式语法，点击「预览匹配数」确认有匹配。注意Swift代码中的特殊字符需要转义。

### Q6: 如何在Windows上安装IPA到Apple TV
**A:** 推荐使用爱思助手或3uTools：
1. Apple TV通过USB-C连接电脑
2. 打开爱思助手
3. 选择「应用游戏」→「安装应用」
4. 选择IPA文件
5. 等待安装完成
